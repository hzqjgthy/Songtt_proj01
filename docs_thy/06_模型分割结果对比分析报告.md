## 1. 报告结论摘要

本项目当前实际可用数据是头颅 CT 数据，不是 MRI 数据。已有工作记录中对 DICOM 头信息的统计为 `CT=1001`、`MR=0`、`UNKNOWN=2`，因此本报告所有分割结果都应理解为“当前 CT 数据上的结果”，不能外推为 MRI/fMRI/CTA 上的结果。

当前测试过的分割相关方法可以分为两类：

| 类别 | 方法/模型 | 当前状态 | 主要用途 |
|---|---|---|---|
| CT 规则/几何流程 | HU 阈值 + 形态学 + 连通域 + 解剖几何先验 | 已跑通，是当前主流程基础 | 颅骨、颅腔、脑组织、血肿、血管风险区、功能区近似、部分脑室/脑干基线 |
| FreeSurfer SynthSeg standard | `mri_synthseg --ct` | 已测试并接入过脑室/脑干导出 | 解剖标签分割，主要用于脑室和脑干 |
| FreeSurfer SynthSeg robust | `mri_synthseg --robust --ct` | 已测试并完成流程级接入 | 比 standard 更稳定，推荐作为脑室/脑干候选输出 |
| FreeSurfer SynthSeg parc | `mri_synthseg --parc --ct` | 已测试成功 | 额外输出皮层/脑区 parcellation，但功能区映射尚未建立 |
| FreeSurfer SynthStrip | `mri_synthstrip` | 两次被系统杀掉，退出码 137 | 当前机器资源下不适合接入 |
| FreeSurfer SynthSR | `mri_synthsr --ct` | 已测试成功 | 生成 synthetic 1mm MP-RAGE 辅助体数据，不是直接分割模型 |
| FreeSurfer SynthMorph rigid | `mri_synthmorph register -m rigid` | 已测试成功 | 配准模型，不直接产生分割 mask |

总体判断：

1. 颅骨、颅腔、脑组织、血肿、血管风险区仍应保留 CT 规则流程，因为这些任务强依赖 CT HU 值或当前数据条件，SynthSeg 不能直接替代。
2. 脑室分割上，SynthSeg standard/robust 与 CT 规则结果有中等一致性。0099039449 的 standard vs logic Dice 为 `0.673`，0100297683 的 standard vs logic Dice 为 `0.707`，robust vs logic Dice 为 `0.715`。SynthSeg 倾向于给出更大的脑室体积。
3. 脑干分割上，CT 几何近似与 SynthSeg 解剖标签几乎不重叠，不能用 Dice 直接判断谁更准确；它们实际上代表两种不同定义。SynthSeg 更接近真实解剖标签，CT 几何方法更像路径规划中的保守禁区。
4. Standard SynthSeg 在 0100297683 上出现明显质量失效，QC 极低，脑干输出碎片化；Robust 在同病例上 QC 明显恢复，脑室与 standard 高度一致，脑干输出也更完整。因此后续如果替换脑室/脑干，优先使用 SynthSeg Robust，而不是 standard。
5. SynthSeg Parc 在 0099039449 上的脑室/脑干结果与 standard 完全一致，价值主要在额外皮层分区；但在没有 label-to-function 映射前，不能替代当前功能区几何近似。
6. 当前没有人工标注金标准。本报告中的 Dice/Jaccard 是“模型间一致性指标”，不是医学真实准确率。

## 3. 各模型/方法说明

### 3.1 CT 规则/几何流程

该流程不是深度学习模型，而是当前项目最稳定的 CT 基线方法。它包含：

- 颅骨分割：骨窗 CT + HU 阈值 + 连通域。
- 颅腔/脑组织/血肿：颅骨闭合填洞、脑组织 HU 范围、血肿 HU 和形态学过滤。
- 脑室：CSF HU 范围 + 距骨过滤 + 连通域。
- 血管风险区：平扫 CT 高密度结构 + 上矢状窦/大脑镰/颅底血管区几何先验。
- 脑干：颅腔下部中线几何盒 + HU 约束。
- 功能区：运动、语言、视觉、深部核团的颅腔归一化几何近似。

优点：

- 与 CT HU 物理含义一致，适合颅骨、血肿、高密度风险区。
- 不依赖额外权重和 GPU。
- 输出稳定，可解释，容易调参。

局限：

- 脑干和功能区不是精确解剖分割，只是路径规划禁区近似。
- 平扫 CT 不能真实分割未钙化血管；当前血管结果是风险禁区，不是真实血管管腔。
- 功能区精确分割需要 MRI/T1 atlas、fMRI 或 DTI，本项目当前没有 MRI 数据。

### 3.2 SynthSeg Standard

测试命令核心参数：

```text
mri_synthseg --ct --cpu --keepgeom --addctab
```

在本项目中主要用于：

- 脑室标签：`4, 5, 14, 15, 43, 44`
- 脑干标签：`16`

优点：

- 能直接输出标准解剖标签，脑室形态比单纯 HU 阈值更接近脑室解剖。
- 对 0099039449 的 QC 尚可，脑室/脑干输出整体可用。

问题：

- 对 0100297683 出现严重质量问题，QC 几乎全部接近 0，脑干分割碎片化，不能作为自动可靠结果。
- 对 CT 数据的稳定性不如 robust。

### 3.3 SynthSeg Robust

测试命令核心参数：

```text
mri_synthseg --robust --ct --cpu --keepgeom --addctab
```

在本项目中已通过 `pipeline.model_trials.json` 接入流程，生成 `_synthseg_robust.nii.gz`、`_synthseg_robust_volumes.csv`、`_synthseg_robust_qc.csv`，并导出脑室/脑干 mask。

优点：

- 0099039449 上与 standard 的脑室/脑干高度一致。
- 0100297683 上明显修复 standard 的 QC 失效问题。
- 更适合作为当前 CT 流程中脑室/脑干替代输出。

局限：

- Robust 仍不是 CT 专病灶模型，不能替代血肿、颅骨、血管风险区。
- 对脑干的输出体积和位置仍需要人工 overlay 复核。

### 3.4 SynthSeg Parc

测试命令核心参数：

```text
mri_synthseg --parc --ct --cpu --keepgeom --addctab
```

测试结果表明：0099039449 上，parc 的脑室和脑干标签结果与 standard 完全一致；它的新增价值在于输出更多皮层 parcellation 标签。

当前不直接替代功能区模块，原因是：

- 项目当前需要的是运动区、语言区、视觉区、深部核团等“路径规划功能禁区”。
- Parc 输出的是皮层解剖标签，需要先建立明确 label 映射，例如 precentral/postcentral、pericalcarine、Broca/Wernicke 近似区等。
- 没有 MRI atlas 配准和人工验证前，直接用 parc 替代功能区几何近似风险较高。

### 3.5 SynthStrip

SynthStrip 已用 0.80 mm 和 5.00 mm CT 输入分别测试，均在 CPU 推理阶段被系统杀掉，退出码 `137`。这通常意味着当前会话资源不足或进程被系统终止。

结论：当前机器/环境下不接入 SynthStrip，不纳入可用分割结果对比。

### 3.6 SynthSR 与 SynthMorph

SynthSR 和 SynthMorph 都不是直接的分割输出模型：

- SynthSR：把 CT 生成 synthetic 1mm MP-RAGE 风格体数据。0100297683 的测试输出尺寸为 `[265, 265, 185]`，spacing 为 `[1.0, 1.0, 1.0]`，强度范围 `0-255`。它不保留 HU 物理含义，不能直接喂给 HU 阈值分割。
- SynthMorph rigid：完成 CT 序列间 rigid 配准，已生成 LTA 变换和重采样体数据。它适合后续 CT/CTA、CT/MRI 对齐，不直接给出 mask。

因此这两个模型只作为辅助能力记录，不参与“分割 mask 质量”排名。

| 病例 | 对比 | Dice | Jaccard | 交集体积 |
|---|---|---:|---:|---:|
| 0099039449 | logic vs standard | `0.000` | `0.000` | `0.000 mL` |
| 0099039449 | logic vs robust | `0.000` | `0.000` | `0.000 mL` |
| 0099039449 | standard vs robust | `0.901` | `0.821` | `20.483 mL` |

解释：

- Logic 与 SynthSeg 脑干几乎不重叠，不代表 SynthSeg 一定错，也不代表 logic 一定错；根本原因是两者定义不同。

- 0100297683 中 standard 与 robust Dice 仅 `0.337`，结合 standard QC 极低，说明 standard 在该病例上失败，而 robust 更可信。

## 9. 模型选择建议

### 9.1 当前主流程建议

建议保留如下组合：

| 分割目标 | 推荐方法 | 理由 |
|---|---|---|
| 颅骨 | CT 规则流程 | 骨组织 HU 高，对 CT 阈值最稳定 |
| 颅腔/脑组织 | CT 规则流程 | 依赖颅骨闭合和 CT HU，当前效果可解释 |
| 血肿 | CT 规则流程 | 平扫 CT 急性血肿 HU 特征明显，SynthSeg 不处理病灶 |
| 血管风险区 | CT 规则流程 | 当前无 CTA/MRA，只能做风险禁区近似 |
| 脑室 | SynthSeg Robust 优先，logic 作为回退 | Robust 与 standard 高一致，但 QC 更稳定 |
| 脑干 | SynthSeg Robust 优先，同时保留 logic 禁区作安全备份 | Robust 更接近解剖标签，logic 更保守 |
| 功能区 | 暂用 CT 几何近似 | 当前无 MRI/fMRI/DTI，Parc 映射尚未验证 |

### 9.2 不建议直接采用的方案

1. 不建议用 SynthSeg standard 作为无 QC 的默认脑干模型。0100297683 已证明它可能在 CT 上严重失效。
2. 不建议用 SynthSeg Parc 直接替代功能区分割。必须先完成标签映射和人工验证。
3. 不建议把 SynthSR 输出继续输入 HU 阈值分割。SynthSR 是 synthetic MR 风格强度，已经不保留 CT HU 物理意义。
4. 当前不建议接入 SynthStrip。资源条件下推理失败，无法形成稳定输出。

## 10. 后续实验建议

1. 建立人工标注小样本：至少对脑室、脑干、血肿做 2-5 例人工 mask，才能把 Dice/Jaccard 从“模型间一致性”升级为“真实准确率”。
2. 给 SynthSeg robust 加 QC 自动门控：QC 低时自动回退到 logic，或标记为人工复核。
3. 对脑干输出增加合理体积范围检查。像 0100297683 standard 的 `1.994-3.672 mL` 明显偏小，应自动报警。
4. 给 Parc 建立功能区映射表：例如 precentral/postcentral、pericalcarine、superior temporal、pars opercularis/triangularis 等标签到运动/视觉/语言近似区的映射。
5. 如果后续拿到 MRI 数据，优先用 SynthMorph 做 CT-MRI 配准，再把 MRI 上的脑干、功能区、深部核团分割重采样回 CT 网格。
6. 如果后续拿到 CTA/MRA，当前血管风险区模块应替换为真实血管分割，而不是继续使用平扫 CT 几何先验。

## 11. 最终结论

在当前只有 CT 数据的条件下，最稳妥的方案不是让某一个深度模型替代全部流程，而是采用混合架构：

- CT HU/几何规则继续负责颅骨、颅腔、脑组织、血肿、血管风险区和功能区近似。
- SynthSeg Robust 负责增强脑室和脑干等解剖结构分割。
- SynthSeg Standard 只作为对照，不作为默认自动结果。
- SynthSeg Parc 作为后续功能区/皮层标签扩展候选。
- SynthSR 和 SynthMorph 作为预处理/配准辅助能力，不作为分割质量排名对象。

当前最明确的模型结论是：`SynthSeg Robust` 在本项目 CT 数据上比 `SynthSeg Standard` 更稳定，尤其在 0100297683 上避免了 standard 的严重 QC 失效；但所有模型输出在进入路径规划或临床解释前仍需要 overlay 复核和 QC 门控。
