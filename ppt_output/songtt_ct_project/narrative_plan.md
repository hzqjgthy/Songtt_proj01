# 脑出血 CT 影像分割与穿刺路径规划汇报 PPT 计划

## 受众

项目汇报对象：非医学背景或医学/技术混合听众。需要说明项目在做什么、每一步如何运行、产出是什么、当前结果如何、局限在哪里。

## 目标

用一套清晰的汇报型 PPT 展示从原始 DICOM 到路径规划和 PDF 报告的完整闭环。强调这是规则和几何驱动的辅助分析原型，不是临床自动诊断系统。

## 叙事线

1. 先说明项目目标：从 CT 数据中自动提取关键结构，并规划避开风险区的穿刺路径。
2. 展示数据和整体流水线。
3. 逐步讲解 DICOM 转换、颅骨、颅腔/血肿、脑室、血管风险、脑干、功能区、路径规划、报告生成。
4. 用当前两个病例的统计结果和代表图支撑。
5. 最后说明临床和算法局限，以及后续改进方向。

## 幻灯片列表

1. 封面：项目名称、核心目标、当前数据规模。
2. 项目目标与交付物：输入、处理、输出。
3. 数据与运行结果概览：2 个病例、8 个序列转换、1 个病例检出血肿。
4. 全流程总览：9 步流水线。
5. 步骤 1：DICOM 转 NIfTI。
6. 步骤 2：颅骨分割。
7. 步骤 3：颅腔、脑组织、血肿分割。
8. 步骤 4：脑室分割。
9. 步骤 5：血管风险禁区。
10. 步骤 6-7：脑干和功能区近似禁区。
11. 步骤 8：穿刺路径规划。
12. 步骤 9：自然语言方案与 PDF 报告。
13. 局限性与下一步。

## 视觉系统

风格：医学影像汇报风格，深色背景搭配 CT 灰度图，使用青色/红色/橙色/紫色作为重点标识。页面结构保持简洁、专业、适合项目汇报。

字体：macOS 环境优先使用 Arial / Helvetica / Heiti TC，保证中文显示。

## 素材计划

使用项目输出目录中的真实 PNG 作为代表图片：

- preview 图：展示 DICOM 转换后的三视图。
- skull_overlay / skull_3d：颅骨分割。
- brain_overlay / brain_3d：脑组织和血肿。
- ventricle_overlay / ventricle_3d：脑室。
- vessel_overlay / vessel_3d：血管风险禁区。
- brainstem_overlay / eloquent_overlay：脑干和功能区近似禁区。
- paths_overlay / paths_3d：路径规划。

## 可编辑性计划

PPT 中的标题、说明、统计数字、流程图、表格均使用可编辑 PowerPoint 对象。医学影像图作为图片插入。
